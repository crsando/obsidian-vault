# 主观大结构与量化B类执行策略：逻辑、实测与收益归因

> [!abstract] 核心定位
> 本研究旨在验证 **“主观日线大结构择时（预判未来 1～2 周趋势/震荡） + 日内低周期量化执行（15m / 60m）”** 的混合交易体系。
> 依托 2022–2025 年中金所（CFFEX）真实 Tick 级别清洗数据，重点研究 **B 类（震荡看多/震荡看空的回撤交易）** 策略的实盘逻辑、真实摩擦下的表现、参数稳健性，以及量化入场相对直接持有的真实增量价值。

---

## 1. 策略基本逻辑体系

在混合交易框架中，日线提供**方向过滤器（Regime Gate）**，日内周期负责**执行触发与精确风控**。策略仅在允许的状态下开仓，其他状态禁止开新仓。

```
                  ┌──────────────────────────────────────────────┐
                  │   主观日线大结构判断 (1~2周级别趋势/震荡)   │
                  └──────────────────────┬───────────────────────┘
                                         │ 方向许可 (Gate)
                     ┌───────────────────┴───────────────────┐
                     ▼                                       ▼
       【震荡看多 (range_up)】                  【震荡看空 (range_down)】
         仅允许触发做多信号                      仅允许触发做空信号
                     │                                       │
                     └───────────────────┬───────────────────┘
                                         ▼
                 ┌───────────────────────────────────────────────┐
                 │     量化低周期执行引擎 (15m / 60m Bar)         │
                 │   - 满足超买/超卖/偏离条件                    │
                 │   - 次 Bar 首有效对手价入场 (+1 Tick 滑点)     │
                 │   - 初始硬止损: 2 * ATR20                     │
                 │   - 均线回归平仓 或 最长持有 2 个交易日       │
                 └───────────────────────────────────────────────┘
```

### 1.1 测试的三种候选 B 类策略

全部策略要求：入场信号在完整 Bar 结束时判定，下一根 Bar 首个有效挂单（买一/卖一）撮合；初始止损冻结为 $2 \times \text{ATR}_{20}$；最长持有 2 个交易日；一律不加仓摊平。

#### ① RSI2 回撤策略 (Connors RSI(2) 变体)
- **底层原理**：捕捉均值回归。极短周期（2 期）RSI 能够迅速反映日内盘口的极端恐慌杀跌或非理性冲高。
- **做多规则**：
  $$\text{Wilder RSI}(2) < 10 \quad \text{且} \quad \text{Close} < \text{SMA}_5$$
- **做空规则**：
  $$\text{Wilder RSI}(2) > 90 \quad \text{且} \quad \text{Close} > \text{SMA}_5$$
- **平仓机制**：收盘价回到 $\text{SMA}_5$（多头 $\text{Close} \ge \text{SMA}_5$，空头 $\text{Close} \le \text{SMA}_5$），或触及 2ATR 止损，或达到 2 日时间上限。

#### ② Bollinger Bands 偏离回归策略 (布林带突破反转)
- **底层原理**：基于价格偏离统计均值的极端概率事件（$2\sigma$ 边界），博弈价格向中心趋势收敛。
- **做多规则**：
  $$\text{Close} < \text{SMA}_{20} - 2\sigma \quad (\text{ddof}=0)$$
- **做空规则**：
  $$\text{Close} > \text{SMA}_{20} + 2\sigma \quad (\text{ddof}=0)$$
- **平仓机制**：收盘价回归中轨 $\text{SMA}_{20}$ 即平仓退出，或触及 2ATR 止损。

#### ③ Keltner / EMA20±ATR20 Reclaim (包络线收回确认)
- **底层原理**：防止“飞刀接在半空中”。价格必须先击破外包络（$\text{EMA}_{20} \pm 1\text{ATR}$），随后重新收回带内，确认短期动量衰竭。
- **做多规则**：$\text{Close}_{t-1} < \text{Lower}_{t-1}$ 且 $\text{Lower}_t < \text{Close}_t < \text{EMA}_{20}$。
- **做空规则**：$\text{Close}_{t-1} > \text{Upper}_{t-1}$ 且 $\text{Upper}_t > \text{Close}_t > \text{EMA}_{20}$。
- **平仓机制**：价格回到 $\text{EMA}_{20}$ 退出，或触及 2ATR 止损。

## 2. 回测仿真与严苛对账标准

> [!warning] 拒绝理想化回测陷阱
> 很多低周期回测在实盘失效，根本原因是采用了“未来 Bar 最差价止损”、“均线穿透即成交”等粗暴假设。本套回测体系严格还原了真实微观结构：

1. **真实合约历史与换月**：依据前一交易日全市场持仓量（Open Interest）前瞻选取主力合约，换月单调递增，杜绝跨合约价差跳空污染指标。
2. **严防未来函数**：
   - 指标仅基于当前 Bar 收盘价计算。
   - 开仓成交价取下一根 Bar 启动后 5 秒内的首个有效对手价（加 1 个 Tick 滑点）；超过 5 秒无有效报价则拒绝入场。
3. **逐 Tick 快照级别止损**：
   - 入场后，使用高频 Tick 流中首次穿越止损价的真实买一/卖一快照成交，并附加滑点。不采用整根 Bar 最差价。
4. **摩擦成本情景**：
   - 股指：开仓与平昨 $0.23 \times 10^{-4}$，平今 $2.3 \times 10^{-4}$，加边滑点 1 Tick。
   - 国债：每边 3 元，加边滑点 1 Tick。
   - 压力测试情景：加倍手续费 + 双边 2 Tick 滑点。
5. **归一化风险计量 ($R$)**：
   $$R = \frac{\text{Net PnL}}{2 \times \text{ATR}_0 \times \text{Contract Multiplier}}$$
   每笔交易归一到单位计划初始风险 $1R$，确保跨品种、跨时期的回测结果具备统计可比性。

### 第三轮：灵魂质问——量化执行到底提供了什么增量？

我们在相同自然阶段、相同 2ATR 止损及手续费规则下，设置了四条单仓执行路径：

```
1. B 原规则          : 等待回撤入场 -> 均线回归退出 (或 2ATR 止损 / 2日到期)
2. B 入场+两日退出   : 等待回撤入场 -> 取消均线退出 -> 硬拿满 2 交易日 (或 2ATR 止损)
3. 直接两日持有      : 阶段内每隔 2 天首 Bar 主动建仓 -> 拿满 2 交易日 (纯吃波段)
4. 阶段首日持有      : 阶段第 1 天首 Bar 主动建仓 -> 持仓直至阶段结束 (长波段持有)
```

## 4. 核心洞察与认知颠覆

> [!quote] 核心认知转变
> 很多人误以为量化择时入场是为了“赚取更丰厚的总利润”，但实证给出了相反的事实：
> **如果大方向判断准确，最好的策略是直接开仓拿着不放；任何等待回撤的入场和均线回归平仓，都会因为踏空或过早止盈而损失累计利润。**

### 那么 B 类量化执行的真实价值究竟是什么？

1. **极致的风险暴露压缩**：
   - B 策略在市场里的暴露时间仅为趋势持有的 **$\frac{1}{5} \sim \frac{1}{10}$**。
   - 最大回撤仅为后者的 **$\frac{1}{3} \sim \frac{1}{4}$**。
   - 它追求的不是“全波段吃满”，而是**“资金高周转率 + 极小隔夜敞口 + 高确定性均值回归”**。
2. **均线回归退出的“安全气囊”本质**：
   - **看对时是枷锁**：因为提前落袋，少赚了后续大趋势的利润。
   - **看错时是护甲**：在方向看错的实测中，取消均线平仓的 T 策略亏损由 **$-19.32R$ 暴增至 $-44.13R$**。均线退出的真正价值在于在震荡破位演变成灾难性单边趋势前，利用反抽果断脱身。

## 5. 后续推进与架构建议

1. **组合架构建议（哑铃型配置）**：
   - **核心仓（主攻）**：当主观判断确定性较高时，使用直接短波段持有（如 2～3 日波段持有），吃满日线 beta。
   - **卫星仓（防御/弱势震荡）**：在弱震荡或高风险事件窗口，启用 **IM 15m 布林** 与 **T 60m RSI2**，以极低回撤和快速均线收敛博取稳定 alpha。
2. **容错阈值压力实测**：
   - 下一步应模拟“主观胜率从 100% 衰减到 60%、50%”时，各执行臂的盈亏平衡点（Breakeven Analysis），定量计算主观判断究竟需要多少胜率才能支撑纯波段持有。
3. **资金与整手数工程约束**：
   - 当前实证基于 $1R$ 归一化风险尺度。实盘中股指单手价值高（IM 单笔止损风险常超 2000~5000 元），必须结合真实保证金账户与整数手进行执行层撮合检验。
