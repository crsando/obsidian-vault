## 配料

以下用量适合 **2 kg 牛腱**，一次可以多做一些：

| 食材 | 用量 | 说明 |
| --- | ---: | --- |
| 牛腱 | 2 kg | 分成每块约 500～700 g |
| 清水 | 约 2.5 L | 以基本没过牛肉为准 |
| 生抽 | 50 ml | 主要咸味来源 |
| 老抽 | 10 ml | 只用于上色，可以不放 |
| 盐 | 8～10 g | 如果还要蘸汁，可减至 6～8 g |
| 姜 | 8 片 |  |
| 葱 | 2 根 |  |
| 八角 | 2 颗 |  |
| 桂皮 | 1 小段 |  |
| 香叶 | 3 片 |  |
| 花椒 | 1 小勺 |  |
| 陈皮 | 1 小块 |  |
| 白胡椒 | 少许 |  |
| 冰糖 | 10 g | 可不放 |
| 料酒 | 30 ml |  |
| 干辣椒 | 适量 | 可不放 |

## 做法

1. 牛腱切成每块约 500～700 g，放入冷水浸泡 1～2 小时，中途换一次水。
2. 牛腱冷水下锅，水开后再煮 3 分钟，捞出并洗净浮沫。
3. 将香料装进纱布袋。锅中加入牛肉、香料、葱姜和全部调味料，加水至基本没过牛肉。
4. 煮开后转最小火，保持轻微冒泡，盖盖卤 1.5～2 小时。筷子能扎进去、但仍有一点阻力时关火。
5. 牛肉留在卤汁中自然冷却，再放入冰箱冷藏浸泡 6～12 小时。**低盐卤味主要靠这一步入味。**
6. 第二天捞出擦干，冷藏后逆着纹理切成薄片。

> [!tip] 压力锅做法
> 上压后煮约 30～35 分钟，然后自然泄压。不要压得过烂，否则冷切时容易碎。

## 批量保存

- 未来 **3 天内**要吃的放冷藏，分装时尽量少带卤汁。
- 其余按每顿 150～250 g 分装冷冻，建议整块保存，口感比切片后冷冻更好。
- 冷冻后建议在 **1～2 个月**内吃完。
- 食用前一晚移入冷藏室解冻，避免室温解冻和反复冻融。
- 卤汁过滤、重新煮沸后分装冷冻。低盐卤汁不适合长期冷藏，也不建议长期反复续作“老卤”。

## 吃法与减盐要点

- 搭配黄瓜、番茄、焯青菜或杂粮饭。
- 蘸汁用醋、蒜末、辣椒和少量卤汁调制，不再额外倒酱油。
- 少用酱油，利用葱姜、香料、陈皮和冷藏浸泡增加风味。
- 低盐并不会延长保存期，因此大量制作时应以分装冷冻为主。
