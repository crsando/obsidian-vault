## 二、核心决策逻辑与关键认知纠偏

### 1. 认知纠偏一：为什么只跑 27B 时，“二手 M2 Ultra 64GB” 是性价比盲点？
- **物理带宽决定生成速度**：Mac Studio M2 Ultra 全系（无论是 64GB、128GB 还是 192GB）均采用双 UltraFusion 互联，统一内存位宽 800-bit，**物理带宽均为 800 GB/s**。
- **27B 模型内存完全够用**：
  - **Qwen3.8-27B 4-bit（oQ4e / Q4_K_M）占用**：**16.5 GB**；
  - **macOS 系统与日常桌面占用**：**~12 GB**；
  - **32K 上下文 KV Cache + GDN 状态占用**：仅 **~4 GB**（混合注意力 16 层 Full Attention 特性）；
  - **运行时峰值内存占用**：**~33–36 GB**，在 64GB 机器上依然剩余近 **28–30GB 缓冲空间**。
- **结论**：如果核心目标是运行 27B 模型，**64GB 版与 192GB 版吐字速度完全一样（50–57 tok/s）**，但二手价格立省 **¥5,000–7,000**。

### 2. 认知纠偏二：为什么“双 RTX 3090 24G”是长研报体验最好的方案？
- **解决长文档首字延迟（TTFT）痛点**：
  - 研报与财报分析通常单次喂入 1–2 万字（15K–30K tokens）。
  - 在 Mac 上 Prefill 算力弱，输入 32K 长文本后需要**干等近 2 分钟**（TTFT 约 113 秒）；
  - 在 **双 RTX 3090 24G（48GB）** 的 CUDA 算力下，**3–5 秒内瞬间开始吐字**，体验质的飞跃。
- **高精度与并发能力**：
  - 48GB 显存可直接加载 **Q8_0 / FP8 高精度版本（约 28GB）**，提取财报数字更精确；
  - 支持 `vLLM` 的 Tensor Parallelism（TP=2），多 Agent 并发与图表多模态输入毫无显存压力。

### 3. 为什么 NVIDIA 单卡方案（5090D / 4090）出局？
- **国行 5090D 仅 24GB 显存**：4-bit 权重占用 16GB 后仅剩 6–7GB 可用，一旦开启长上下文、多轮推理或高分辨率图表输入极易 OOM；
- **单卡价格严重倒挂**：单张 5090D 售价高达 **¥20,000–30,000**，而两张二手 3090 24G 仅需 **¥1.3–1.5 万（含整机）** 即可获得 48GB 显存。

## 三、针对达叔研究场景的选型落地建议

1. **追求长研报秒响应、不在意主机放在书房角落 / 阳台**：
   - **推荐方案**：**组装双二手 RTX 3090 24G 服务器（整机约 ¥1.35 万）**。
   - **部署方式**：Ubuntu 24.04 + `vLLM`，以局域网标准 OpenAI API 格式暴露，终端/Obsidian/Alma 远程无缝调用。
2. **追求桌面一体化、极度静音、低功耗省心**：
   - **推荐方案**：**选购二手 Mac Studio M2 Ultra 64GB（目标成交价 ¥1.25–1.35 万）**。
   - **部署方式**：`oMLX / MLX-LM` 4-bit 优化路径，日常功耗仅 50W，静音无感运行。
3. **追求官方一手质保、买新不买旧**：
   - **推荐方案**：**Apple 官网 Mac Studio M5 Max 64GB/128GB（约 ¥2.3–2.8 万）**。
   - **部署方式**：享 M5 架构 Prefill 性能提升与官方售后。
