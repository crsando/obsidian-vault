## 一、三条核心原理（先记住，否则表格看懵）

1. **decode（生成速度）是 memory-bound**：≈ 内存带宽 ÷ 单 token 权重字节数（27B 4bit ≈ 17GB）。**带宽为王**。
2. **prefill（首字延迟 TTFT）是 compute-bound**：由 GPU 算力（FLOPs）决定，跟带宽无关。**Mac GPU 算力弱 = 首字延迟是 Mac 通病，换任何 Mac 都治不好，只有 N 卡能救。**
3. **Agent 真实速度 = 每步多快 × 走多少步 × 链路能否坚持到最后**（微信文章横评的核心结论）。**低精度量化会让 agent 走弯路；端到端赢家是"大显存 + 高精度量化 + 稳定跑完"，不是 tok/s 最快。**

## 五、关键结论精华（今天的调研沉淀）

1. **M4 Max 36GB/64GB 都有 binned 陷阱**：36GB 是 410GB/s（14核+32核），64GB 也有 14核(410)/16核(546)两种，买错差 25%。
2. **Qwen3.8 在 Mac 上裸跑只有 13-15 tok/s**（新架构 kernel 未优化），但开 MTP 后能到 38-53；瓶颈是 kernel 不是内存。
3. **首字延迟是算力问题，Mac 治不好**：M3 Ultra 256GB 跑 65K 要等 5 分钟首字，5090 只要 0.4 秒。
4. **端到端 agent 赢家是"大显存 + 高精度量化"**：双 A40 Q8_0 墙钟最短，低精度量化（NVFP4/Q4）会让 agent 走弯路。
5. **性价比三巨头**：RX 7900 XTX 二手（4200-4800）、M2 Ultra 192GB 二手（1.8-2.3万）、双二手 3090（1.3-1.5万含整机，前序调研）。
6. **MTP 是速度头号开关**：开不开差一倍，看别人晒速度先问开没开 MTP。
