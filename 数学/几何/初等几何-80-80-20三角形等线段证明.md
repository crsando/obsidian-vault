# 几何竞赛题：$80^\circ$-$80^\circ$-$20^\circ$ 等腰三角形中的等线段证明

## 一、题目描述

在 $\triangle ABC$ 中，$\angle BAC = \angle ABC = 80^\circ$，$\angle BCA = 20^\circ$。$D$ 是 $AC$ 边上一点，满足 $\angle DBC = 10^\circ$。

求证：$AB = CD$。

## 二、原解答诊断与错误剖析

原题提供的 ***Solution*** 存在多处严重的逻辑断层、概念错误与强行凑结论的伪证痕迹，无法构成有效证明。具体硬伤如下：

1. **旋转方向与点的位置完全矛盾（致命硬伤）**：
   - 原文称：“以 $B$ 为中心，将 $\triangle BDC$ 逆时针旋转 $60^\circ$ 得到 $\triangle BFE$”，但随后却计算 $\angle ABE = \angle ABC - \angle EBC = 80^\circ - 60^\circ = 20^\circ$。逆时针旋转会使点 $E$ 远离边 $BA$（若 $B$ 在左下，逆时针旋转得到的点 $E$ 使得 $\angle ABE = 80^\circ + 60^\circ = 140^\circ$）；即便是向 $BA$ 方向旋转（顺时针），$\angle ABE = 20^\circ \neq 0^\circ$ 且 $\neq 180^\circ$。
   - 原文声称“利用 $\triangle ABE$ 的角度关系可知 $E$ 落在直线 $AB$ 上（或其延长线附近）”，这是严重违背几何公理的推论。射线 $BE$ 与射线 $BA$ 有 $20^\circ$ 夹角，$E$ 绝不可能落在直线 $AB$ 上，竞赛证明中绝不存在“落在直线附近”这种妥协性伪证。

2. **角度推导胡乱拼凑与恒等式化**：
   - 原文写道：“$\angle FDA = \angle FDB - \angle ADB = 90^\circ - 30^\circ = 60^\circ = \angle FDA$”。正三角形 $\triangle BFD$ 的内角是 $60^\circ$，不知从何而来 $90^\circ$；且算式最终竟得出一个毫无意义的自身恒等式。

3. **凭空捏造对称轴与全等关系**：
   - 原文宣称：“即 $AD$ 平分 $\angle FDB$，$\triangle BFD$ 以 $AD$ 为对称轴，$AB = AF$”。实际上 $D$ 是 $AC$ 上的固定点，$AD$ 是直线 $AC$，它既不过点 $B$ 和 $F$ 的中垂线，更不可能是正三角形 $\triangle BFD$ 的对称轴，$AB = AF$ 纯属臆造。

4. **共圆与后续逻辑全盘崩溃**：
   - 后续推导中所谓“$\angle FCA = \angle BCA = 20^\circ$”、“$F, E, C, A$ 四点共圆”全部建立在前述错误的虚假对称之上，整篇证明全盘失效。

## 三、标准严谨的纯几何证明（构造等边三角形）

本题属于经典的 Langley 偶然角问题家族。最漂亮、辅助线最少且符合初中竞赛要求的解法是**在底边上构造等边三角形**。

### 辅助线作法

在底边 $AB$ 同侧（$\triangle ABC$ 内部）作等边三角形 $\triangle ABE$。连结 $CE$。

---

![80-80-20三角形辅助线解答配图](https://raw.githubusercontent.com/crsando/picgo/main/geometry-p15-solution-20261020.svg)

---

### 证明步骤

#### 1. 确定对称轴与角度平分
因为 $\triangle ABE$ 为等边三角形，所以：
$$EA = EB = AB, \quad \angle EAB = \angle EBA = 60^\circ$$

在 $\triangle ABC$ 中，已知 $\angle BAC = \angle ABC = 80^\circ$，故 $\triangle ABC$ 是以 $C$ 为顶点的等腰三角形，即：
$$CA = CB$$

又因为 $EA = EB$，点 $C$ 与点 $E$ 都在底边 $AB$ 的垂直平分线上。
因此，直线 $CE$ 是线段 $AB$ 的垂直平分线，同时也是等腰 $\triangle ABC$ 顶角 $\angle ACB$ 的平分线。

由此可得：
$$\angle ACE = \frac{1}{2}\angle ACB = \frac{1}{2} \times 20^\circ = 10^\circ$$

#### 2. 计算 $\triangle EAC$ 的角
在顶点 $A$ 处：
$$\angle EAC = \angle BAC - \angle EAB = 80^\circ - 60^\circ = 20^\circ$$

#### 3. 证明三角形全等（ASA）
考察 $\triangle EAC$ 与 $\triangle DCB$：
1. $\angle ACE = 10^\circ = \angle DBC$（题目已知 $\angle DBC = 10^\circ$）
2. $AC = BC$（等腰三角形腰长相等）
3. $\angle EAC = 20^\circ = \angle DCB$（已知 $\angle DCB = \angle ACB = 20^\circ$）

根据角边角定理（ASA）：
$$\triangle EAC \cong \triangle DCB$$

#### 4. 得出结论
由全等三角形对应边相等：
$$CD = AE$$

又因 $\triangle ABE$ 为等边三角形，$AE = AB$。

综合两式，即得：
$$AB = CD$$

证毕。

## 四、解法二：三角法（正弦定理速验）

在竞赛现场或答题验证中，三角法可以极其迅速地验证结论的正确性。

设 $\triangle ABC$ 的外接圆半径为 $R$。

1. 在等腰 $\triangle ABC$ 中，根据正弦定理：
   $$AB = 2R \sin(\angle BCA) = 2R \sin 20^\circ$$
   $$BC = 2R \sin(\angle BAC) = 2R \sin 80^\circ$$

2. 在 $\triangle BCD$ 中，计算各内角：
   $$\angle BCD = 20^\circ, \quad \angle DBC = 10^\circ$$
   $$\angle BDC = 180^\circ - 20^\circ - 10^\circ = 150^\circ$$

3. 在 $\triangle BCD$ 中应用正弦定理：
   $$\frac{CD}{\sin(\angle DBC)} = \frac{BC}{\sin(\angle BDC)}$$
   $$\frac{CD}{\sin 10^\circ} = \frac{BC}{\sin 150^\circ}$$

   因为 $\sin 150^\circ = \sin 30^\circ = \frac{1}{2}$，整理得：
   $$CD = \frac{BC \cdot \sin 10^\circ}{\frac{1}{2}} = 2 BC \sin 10^\circ$$

4. 将 $BC = 2R \sin 80^\circ$ 代入：
   $$CD = 2 \cdot (2R \sin 80^\circ) \cdot \sin 10^\circ = 4R \sin 80^\circ \cos 80^\circ$$
   根据正弦二倍角公式 $2\sin\theta\cos\theta = \sin 2\theta$：
   $$CD = 2R \sin(2 \times 80^\circ) = 2R \sin 160^\circ = 2R \sin 20^\circ$$

5. 对比两式：
   $$CD = 2R \sin 20^\circ = AB$$

故 $AB = CD$ 成立。

```tex
\documentclass[border=15pt]{standalone}
\def\pgfsysdriver{pgfsys-dvisvgm.def}
\usepackage{amsmath}
\usepackage{tikz}
\usetikzlibrary{calc,angles,quotes}

\begin{document}
\begin{tikzpicture}[scale=1.1, line cap=round, line join=round, >=stealth]
    % Coordinates
    \coordinate (A) at (-1.5, 0);
    \coordinate (B) at (1.5, 0);
    \coordinate (C) at (0, {1.5 * tan(80)});
    \coordinate (D) at ($(C)!{2*cos(80)}!(A)$);
    \coordinate (E) at (0, {1.5 * sqrt(3)});

    % Shaded congruent triangles for high contrast
    \fill[cyan!25] (E) -- (A) -- (C) -- cycle;
    \fill[orange!28] (D) -- (C) -- (B) -- cycle;

    % Main Triangle edges
    \draw[line width=1.1pt, color=black] (A) -- (B) -- (C) -- cycle;

    % BD line
    \draw[line width=1.1pt, color=blue!80!black] (B) -- (D);

    % Auxiliary Equilateral Triangle ABE
    \draw[line width=1.1pt, color=teal!85!black] (A) -- (E) -- (B);

    % Symmetry axis CE
    \draw[line width=1.0pt, dashed, color=red!75!black] (C) -- (E);

    % Vertices
    \filldraw[black] (A) circle (1.8pt) node[below left=2pt] {$A$};
    \filldraw[black] (B) circle (1.8pt) node[below right=2pt] {$B$};
    \filldraw[black] (C) circle (1.8pt) node[above=2pt] {$C$};
    \filldraw[blue!80!black] (D) circle (1.8pt) node[left=2pt] {$D$};
```
