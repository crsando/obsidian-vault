# 初中数学竞赛平面几何经典选讲：偶然角与正三角形构造

### 1

在 $\triangle ABC$ 中，$AB = AC$，$\angle BAC = 20^\circ$，$\angle ABC = \angle ACB = 80^\circ$。$D$ 是 $AC$ 边上一点，满足 $\angle DBC = 60^\circ$；$E$ 是 $AB$ 边上一点，满足 $\angle ECB = 50^\circ$。

求：$\angle EDB$ 的度数。

![Langley问题题目配图](https://raw.githubusercontent.com/crsando/picgo/main/p1_prob-20261020.svg)

***Solution***

在 $AC$ 上取一点 $G$，使得 $\angle CBG = 20^\circ$。连结 $DG, EG$。

![Langley问题解答配图](https://raw.githubusercontent.com/crsando/picgo/main/p1_sol-20261020.svg)

1. 在 $\triangle BCG$ 中，$\angle CBG = 20^\circ$，$\angle BCG = 80^\circ \implies \angle BGC = 80^\circ$，故 $BG = BC$。
2. 考察 $\triangle BCE$：$\angle EBC = 80^\circ$，$\angle ECB = 50^\circ \implies \angle BEC = 50^\circ$，故 $BE = BC$。
   结合 $BG = BC$，得 $BE = BG$。
   又 $\angle EBG = \angle ABC - \angle CBG = 80^\circ - 20^\circ = 60^\circ$，故 $\triangle BGE$ 是正三角形，得 $EG = BG = BE$，$\angle BGE = 60^\circ$。
3. 考察 $\triangle BDG$：
   $\angle DBG = \angle DBC - \angle CBG = 60^\circ - 20^\circ = 40^\circ$。
   在 $\triangle BCD$ 中，$\angle BDC = 180^\circ - 60^\circ - 80^\circ = 40^\circ$。
   故 $\angle BDC = \angle DBG = 40^\circ \implies GD = GB$。
4. 综合以上：$GD = GE$（均等于 $BG$），故 $\triangle GDE$ 是等腰三角形。
   顶角 $\angle DGE = 180^\circ - \angle BGC - \angle BGE = 180^\circ - 80^\circ - 60^\circ = 40^\circ$。
   底角 $\angle GDE = \frac{180^\circ - 40^\circ}{2} = 70^\circ$。
5. 在等腰 $\triangle BDG$ 中，$GD = GB$，顶角 $\angle DBG = 40^\circ \implies \angle BDG = \frac{180^\circ - 40^\circ}{2} = 70^\circ$。
   因此：
   $$\angle EDB = \angle GDE - \angle BDG = 70^\circ - 40^\circ = 30^\circ$$

### 2

在正方形 $ABCD$ 内部有一点 $P$，满足 $\triangle PBC$ 为等腰三角形，且 $\angle PBC = \angle PCB = 15^\circ$。

求证：$\triangle PAD$ 是正三角形。

![正方形15度问题题目配图](https://raw.githubusercontent.com/crsando/picgo/main/p2_prob-20261020.svg)

***Solution***

采用同一法。在正方形内部以 $AD$ 为边作正三角形 $\triangle P'AD$。连结 $P'B, P'C$。

![正方形15度问题解答配图](https://raw.githubusercontent.com/crsando/picgo/main/p2_sol-20261020.svg)

1. 由正三角形性质：$P'A = P'D = AD = AB$。
2. 在 $\triangle P'AB$ 中，$P'A = AB$，故 $\triangle P'AB$ 为等腰三角形。
   顶角 $\angle P'AB = \angle DAB - \angle P'AD = 90^\circ - 60^\circ = 30^\circ$。
   底角 $\angle P'BA = \frac{180^\circ - 30^\circ}{2} = 75^\circ$。
3. 计算 $\angle P'BC$：
   $$\angle P'BC = \angle ABC - \angle P'BA = 90^\circ - 75^\circ = 15^\circ$$
4. 同理，由轴对称性可知 $\angle P'CB = 15^\circ$。
5. 因为在正方形 $ABCD$ 内部，满足 $\angle PBC = \angle PCB = 15^\circ$ 的点 $P$ 唯一，所以点 $P$ 与点 $P'$ 重合。
   故 $\triangle PAD$ 是正三角形。

### 3

在 $\triangle ABC$ 中，顶角 $\angle BAC = 100^\circ$，底角 $\angle ABC = \angle ACB = 40^\circ$。$BD$ 平分 $\angle ABC$ 交 $AC$ 于点 $D$。

求证：$BC = BD + AD$。

![100-40-40三角形题目配图](https://raw.githubusercontent.com/crsando/picgo/main/p3_prob-20261020.svg)

***Solution***

在 $BC$ 上分别截取 $BE = BD$，$BF = BA$。连结 $DE, DF$。

![100-40-40三角形解答配图](https://raw.githubusercontent.com/crsando/picgo/main/p3_sol-20261020.svg)

1. **截取 $BE = BD$：**
   因为 $BD$ 平分 $\angle ABC = 40^\circ$，所以 $\angle DBE = 20^\circ$。
   在等腰 $\triangle BDE$ 中，底角 $\angle BED = \angle BDE = \frac{180^\circ - 20^\circ}{2} = 80^\circ$。
   故 $\angle DEC = 180^\circ - 80^\circ = 100^\circ$。
   在 $\triangle CDE$ 中，$\angle C = 40^\circ \implies \angle CDE = 180^\circ - 100^\circ - 40^\circ = 40^\circ = \angle C$。
   因此 $EC = ED$，得 $BC = BE + EC = BD + ED$。

2. **截取 $BF = BA$：**
   在 $\triangle BFD$ 与 $\triangle BAD$ 中：
   $$\begin{cases}
   BF = BA \\
   \angle FBD = \angle ABD = 20^\circ \\
   BD = BD
   \end{cases} \implies \triangle BFD \cong \triangle BAD \quad (\text{SAS})$$
   故 $DF = AD$，且 $\angle BFD = \angle BAD = 100^\circ$。
   邻补角 $\angle DFE = 180^\circ - 100^\circ = 80^\circ$。

3. **转移线段：**
   在 $\triangle DFE$ 中，$\angle DFE = 80^\circ$，且前面已得 $\angle DEF = \angle DEB = 80^\circ$。
   故 $\triangle DFE$ 为等腰三角形，得 $ED = DF = AD$。
   代入即得：
   $$BC = BD + AD$$

### 4

在 $\triangle ABC$ 中，$CA = CB$，顶角 $\angle BCA = 20^\circ$，底角 $\angle BAC = \angle ABC = 80^\circ$。$D$ 是 $AC$ 边上一点，满足 $\angle CBD = 30^\circ$。

求证：$AD = AB$。

![80-80-20逆向定角定理题目配图](https://raw.githubusercontent.com/crsando/picgo/main/p4_prob-20261020.svg)

***Solution***

在 $\triangle ABD$ 中倒角即可。

![80-80-20逆向定角定理解答配图](https://raw.githubusercontent.com/crsando/picgo/main/p4_sol-20261020.svg)

1. 计算 $\angle ABD$：
   $$\angle ABD = \angle ABC - \angle CBD = 80^\circ - 30^\circ = 50^\circ$$
2. 在 $\triangle ABD$ 中，已知 $\angle BAD = 80^\circ$：
   $$\angle ADB = 180^\circ - \angle BAD - \angle ABD = 180^\circ - 80^\circ - 50^\circ = 50^\circ$$
3. 因为 $\angle ABD = \angle ADB = 50^\circ$，所以 $\triangle ABD$ 是以 $A$ 为顶点的等腰三角形：
   $$AD = AB$$
