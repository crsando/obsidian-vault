# 锐角三角形余弦和不等式的证明

对于任意锐角三角形 $ABC$，证明以下不等式成立：
$$\cos A + \cos B + \cos C \le \frac{3}{2}$$

此不等式在等边三角形时等号成立（即 $A = B = C = \frac{\pi}{3}$）。以下提供三种经典的证明方法：代数法（Jensen 不等式）、三角恒等变形法以及纯几何法。

---

## 方法一：代数法（利用 Jensen 不等式）

**思路**：利用余弦函数在锐角区间内的凹凸性。

1. **函数凹凸性**：
   在锐角三角形中，$A, B, C \in \left(0, \frac{\pi}{2}\right)$。
   设函数 $f(x) = \cos x$，求导分析：
   $$f'(x) = -\sin x$$
   $$f''(x) = -\cos x < 0$$
   因此，$f(x) = \cos x$ 在区间 $\left(0, \frac{\pi}{2}\right)$ 内是**严格上凸（凹）函数**。

2. **应用 Jensen 不等式**：
   根据 Jensen 不等式，对于凸区间内的任意三个数 $A, B, C$，有：
   $$\frac{\cos A + \cos B + \cos C}{3} \le \cos\left(\frac{A+B+C}{3}\right)$$

3. **代入内角和 $A+B+C = \pi$**：
   $$\frac{\cos A + \cos B + \cos C}{3} \le \cos\left(\frac{\pi}{3}\right) = \frac{1}{2}$$
   两边同乘以 3 即得：
   $$\cos A + \cos B + \cos C \le \frac{3}{2}$$

**等号成立条件**：当且仅当 $A = B = C = \frac{\pi}{3}$（等边三角形）时成立。

---

## 方法二：三角恒等变形与配方法（适用于任意三角形）

**思路**：利用和差化积公式与二次函数配方。此方法不限于锐角三角形。

1. **和差化积展开前两项**：
   $$\cos A + \cos B = 2 \cos\frac{A+B}{2} \cos\frac{A-B}{2}$$

2. **利用内角和转化第三项**：
   因为 $A+B+C = \pi$，所以 $\frac{A+B}{2} = \frac{\pi}{2} - \frac{C}{2}$。
   代入得：
   $$\cos\frac{A+B}{2} = \sin\frac{C}{2}$$
   利用倍角公式展开 $\cos C$：
   $$\cos C = 1 - 2\sin^2\frac{C}{2}$$

3. **代入原式进行放缩**：
   $$\cos A + \cos B + \cos C = 2 \sin\frac{C}{2} \cos\frac{A-B}{2} + 1 - 2\sin^2\frac{C}{2}$$
   因为 $\cos\frac{A-B}{2} \le 1$ 且 $\sin\frac{C}{2} > 0$（因为 $C \in (0, \pi)$），故：
   $$\cos A + \cos B + \cos C \le -2\sin^2\frac{C}{2} + 2\sin\frac{C}{2} + 1$$

4. **二次函数配方**：
   设 $t = \sin\frac{C}{2}$，对 $-2t^2 + 2t + 1$ 配方：
   $$-2t^2 + 2t + 1 = -2\left(t - \frac{1}{2}\right)^2 + \frac{3}{2}$$
   因为 $-2\left(t - \frac{1}{2}\right)^2 \le 0$，所以：
   $$\cos A + \cos B + \cos C \le \frac{3}{2}$$

**等号成立条件**：
1. $\cos\frac{A-B}{2} = 1 \implies A = B$
2. $\sin\frac{C}{2} = \frac{1}{2} \implies C = \frac{\pi}{3}$
即 $A = B = C = \frac{\pi}{3}$。

## 方法三：纯几何法（卡诺定理 + 欧拉不等式）

**思路**：将余弦值转化为外心投影线段，利用几何定理进行放缩。

### 1. 投影转化
设 $\Delta ABC$ 的外心为 $O$，外接圆半径为 $R$。
将 $O$ 投影到三边 $BC, CA, AB$，垂足分别为 $D, E, F$（即三边中点）。
因为 $\Delta ABC$ 是锐角三角形，外心 $O$ 落在三角形内部。
易得：
$$OD = R \cos A, \quad OE = R \cos B, \quad OF = R \cos C$$
原命题等价于证明：
$$OD + OE + OF \le \frac{3}{2} R$$

### 2. 证明卡诺定理（$OD + OE + OF = R + r$）
*   **托勒密定理**：
    四边形 $O E A F$ 中 $\angle OEA = \angle OFA = 90^\circ$，因此 $O, E, A, F$ 四点共圆，直径为 $OA = R$。
    由托勒密定理：
    $$OA \cdot EF = OF \cdot AE + OE \cdot AF$$
    因为 $E, F$ 分别是中点，有 $EF = \frac{a}{2}$，$AE = \frac{b}{2}$，$AF = \frac{c}{2}$。
    代入得：
    $$R a = b \cdot OF + c \cdot OE$$
    同理可得：
    $$R b = c \cdot OD + a \cdot OF$$
    $$R c = a \cdot OE + b \cdot OD$$
    三式相加：
    $$R(a+b+c) = (b+c)OD + (c+a)OE + (a+b)OF \quad \text{—— (式 1)}$$

*   **面积关系**：
    设内切圆半径为 $r$，利用内心和外心分别分割面积：
    $$S = \frac{1}{2} r (a+b+c) = S_{\Delta OBC} + S_{\Delta OCA} + S_{\Delta OAB} = \frac{1}{2} (a \cdot OD + b \cdot OE + c \cdot OF)$$
    可得：
    $$r(a+b+c) = a \cdot OD + b \cdot OE + c \cdot OF \quad \text{—— (式 2)}$$

*   **相加消元**：
    将（式 1）和（式 2）相加，提取公因式 $(a+b+c)$ 并约去：
    $$OD + OE + OF = R + r$$

### 3. 欧拉不等式放缩（$R \ge 2r$）
设外心与内心的距离为 $d$，根据欧拉定理有：
$$d^2 = R(R - 2r)$$
由于 $d^2 \ge 0$，因此有：
$$R \ge 2r \implies \frac{r}{R} \le \frac{1}{2}$$

### 4. 得出结论
代入卡诺定理：
$$\cos A + \cos B + \cos C = \frac{OD + OE + OF}{R} = \frac{R + r}{R} = 1 + \frac{r}{R} \le 1 + \frac{1}{2} = \frac{3}{2}$$

证明完毕。
