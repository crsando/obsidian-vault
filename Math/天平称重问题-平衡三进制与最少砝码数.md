## 题目

> **【例1】** 给定正整数 $n$，已知用克数都是正整数的 $k$ 块砝码和一台天平可以称出质量为 $1, 2, \cdots, n$ 克的所有物品。试求 $k$ 的最小值。

---

## 核心结论

$k$ 的最小值为 **$\lceil \log_3(2n + 1) \rceil$**，即满足 **$\frac{3^k - 1}{2} \ge n$** 的最小正整数 $k$。

最优砝码质量配置为 **$3$ 的幂次序列**：**$1, 3, 9, 27, \dots, 3^{k-1}$** 克。

---

## 证明与解析

### 1. 数学建模（砝码的 3 种状态）

设选取的 $k$ 块砝码质量分别为 $w_1, w_2, \dots, w_k$（均为正整数）。

在天平上称量待测物品（设质量为 $M$）时，对于任意一块砝码 $w_i$，它有且仅有 **3 种放置方式**：
- **放在物品对侧（右盘）**：使天平向砝码侧倾斜，对物品质量贡献为 **$+w_i$**；
- **放在物品同侧（左盘）**：抵消一部分物品质量，对物品质量贡献为 **$-w_i$**；
- **不放在天平上**：对物品质量贡献为 **$0$**。

当且仅当天平平衡时，被称出的物品质量 $M$ 可以表达为：
$$M = \sum_{i=1}^k c_i w_i \quad (c_i \in \{-1, 0, 1\})$$

### 2. 必要性证明（理论下界）

- 系数向量 $(c_1, c_2, \dots, c_k)$ 的所有可能取值总共有 **$3^k$ 种**。
- 其中全 $0$ 组合 $(0, 0, \dots, 0)$ 对应称出质量 $0$。
- 在剩下的 $3^k - 1$ 种非零组合中，由于取反映射 $(c_1, \dots, c_k) \leftrightarrow (-c_1, \dots, -c_k)$ 是一一对应的，每产生一个正质量必定对称地对应一个负质量。
- 因此，这 $k$ 块砝码最多只能组合出 **$\frac{3^k - 1}{2}$ 种不同的正整数质量**。

为了能够完整称出 $1, 2, \dots, n$ 克的所有物品，其能表示的正整数种数必须不小于 $n$：
$$\frac{3^k - 1}{2} \ge n \implies 3^k \ge 2n + 1 \implies k \ge \lceil \log_3(2n + 1) \rceil$$

### 3. 充分性证明（构造法：平衡三进制）

选取 $k$ 块砝码的质量分别为 **$3$ 的幂次方**：
$$w_1 = 1, \quad w_2 = 3, \quad w_3 = 9, \quad \dots, \quad w_k = 3^{k-1}$$

此时砝码总质量为：
$$\sum_{i=0}^{k-1} 3^i = \frac{3^k - 1}{2}$$

根据**平衡三进制（Balanced Ternary）**的基本定理：
> 任意绝对值不超过 $\frac{3^k - 1}{2}$ 的整数 $M$，都存在且仅存在**唯一的平衡三进制表示**：
> $$M = \sum_{i=0}^{k-1} c_i \cdot 3^i \quad (c_i \in \{-1, 0, 1\})$$

因此，$1 \sim \frac{3^k - 1}{2}$ 范围内的**每一个正整数克数都可以被唯一且无遗漏地称量出来**。只要选取 $k = \lceil \log_3(2n + 1) \rceil$，就能确保 $\frac{3^k - 1}{2} \ge n$，满足题意。

## 实例演练（以 $k=3$ 称量 $1 \sim 13$ 克为例）

取三块砝码 $1, 3, 9$ 克，最大可称至 $\frac{3^3 - 1}{2} = 13$ 克：

| 待称质量 | 平衡三进制展开 | 天平称量方案（左盘放物品 $M$） |
| :--- | :--- | :--- |
| **1 g** | $+1$ | 右盘放 $1$ |
| **2 g** | $+3 - 1$ | 左盘加 $1$（即 $M+1$），右盘放 $3$ |
| **3 g** | $+3$ | 右盘放 $3$ |
| **4 g** | $+3 + 1$ | 右盘放 $3 + 1$ |
| **5 g** | $+9 - 3 - 1$ | 左盘加 $3 + 1$，右盘放 $9$ |
| **6 g** | $+9 - 3$ | 左盘加 $3$，右盘放 $9$ |
| **7 g** | $+9 - 3 + 1$ | 左盘加 $3$，右盘放 $9 + 1$ |
| **8 g** | $+9 - 1$ | 左盘加 $1$，右盘放 $9$ |
| **9 g** | $+9$ | 右盘放 $9$ |
| **10 g** | $+9 + 1$ | 右盘放 $9 + 1$ |
| **11 g** | $+9 + 3 - 1$ | 左盘加 $1$，右盘放 $9 + 3$ |
| **12 g** | $+9 + 3$ | 右盘放 $9 + 3$ |
| **13 g** | $+9 + 3 + 1$ | 右盘放 $9 + 3 + 1$ |

## 对比与延伸：单侧称量 vs 双侧称量

- **单侧称量（二进制系统）**：
  若砝码只能放在天平某一侧（只能加不能减），每个砝码只有 $2$ 种状态（放 / 不放），对应**标准二进制** $w_i = 2^{i-1}$。
  $k$ 个砝码最大可称至 $2^k - 1$ 克，所需砝码数为 **$\lceil \log_2(n + 1) \rceil$**。

- **双侧称量（平衡三进制系统）**：
  利用天平两端都可以放置砝码的物理特性，使每个砝码获得 $3$ 种状态（$+1, 0, -1$），对应**平衡三进制** $w_i = 3^{i-1}$。
  $k$ 个砝码最大可称至 $\frac{3^k - 1}{2}$ 克，所需砝码数降为 **$\lceil \log_3(2n + 1) \rceil$**，极大地提升了称量效率。
