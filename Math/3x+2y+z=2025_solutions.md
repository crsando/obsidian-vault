# 3x + 2y + z = 2025 正整数解的组数

## 题目
求下述方程正整数解的组数：
$$ 3x + 2y + z = 2025 $$

## 解答
不难发现 $y \equiv z \pmod{3}$，以此为出发去分类讨论。为了保证求解过程中所有的辅助变量都保持在正整数范围内，我们进行如下设元。

### 情况一：若 $y \equiv z \equiv 0 \pmod{3}$
设 $y = 3b$，$z = 3c$（其中 $b, c \ge 1$ 且为正整数）。代入方程化简为：
$$ 3x + 6b + 3c = 2025 \implies x + 2b + c = 675 $$
由于 $x + c = 675 - 2b$，可知 $x, c$ 必一奇一偶。只需要考虑一种，然后 $\times 2$ 即可。

我们先设 $x = 2a - 1$，$c = 2t$（其中 $a, t \ge 1$ 且为正整数），代入化简为：
$$ (2a - 1) + 2b + 2t = 675 \implies a + b + t = 338 $$
根据隔板法，该方程的正整数解数量为 $C_{337}^2$。另一种情况（$x$ 为偶数，$c$ 为奇数）同理，故情况一共有 $2 \times C_{337}^2$ 种解。

### 情况二：若 $y \equiv z \equiv 1 \pmod{3}$
设 $y = 3b - 2$，$z = 3c - 2$（其中 $b, c \ge 1$ 且为正整数）。代入方程化简为：
$$ 3x + 2(3b - 2) + (3c - 2) = 2025 \implies 3x + 6b + 3c - 6 = 2025 \implies x + 2b + c = 677 $$
由于 $x + c = 677 - 2b$，可知 $x, c$ 必一奇一偶。只需考虑其中一种，再乘以 2 即可。

设 $x = 2a - 1$，$c = 2t$（其中 $a, t \ge 1$ 且为正整数），代入化简为：
$$ (2a - 1) + 2b + 2t = 677 \implies a + b + t = 339 $$
解的数量为 $C_{338}^2$。另一种情况（$x$ 为偶数，$c$ 为奇数）同理，故情况二共有 $2 \times C_{338}^2$ 种解。

### 情况三：若 $y \equiv z \equiv 2 \pmod{3}$
设 $y = 3b - 1$，$z = 3c - 1$（其中 $b, c \ge 1$ 且为正整数）。代入方程化简为：
$$ 3x + 2(3b - 1) + (3c - 1) = 2025 \implies 3x + 6b + 3c - 3 = 2025 \implies x + 2b + c = 676 $$
由于 $x + c = 676 - 2b$，可知 $x, c$ 奇偶性相同（即同奇或同偶）。
- 若 $x, c$ 均为奇数：设 $x = 2a - 1$，$c = 2t - 1$（其中 $a, t \ge 1$ 且为正整数），代入化简为 $2a - 1 + 2b + 2t - 1 = 676 \implies a + b + t = 339$，解的数量为 $C_{338}^2$。
- 若 $x, c$ 均为偶数：设 $x = 2a$，$c = 2t$（其中 $a, t \ge 1$ 且为正整数），代入化简为 $2a + 2b + 2t = 676 \implies a + b + t = 338$，解的数量为 $C_{337}^2$。

因此，情况三共有 $C_{338}^2 + C_{337}^2$ 种解。

### 总结
综上所述，方程的正整数解总组数 $N$ 为：
$$ N = 2 \times C_{337}^2 + 2 \times C_{338}^2 + (C_{338}^2 + C_{337}^2) = 3 \times C_{337}^2 + 3 \times C_{338}^2 $$
计算具体数值：
$$ C_{337}^2 = \frac{337 \times 336}{2} = 56616 $$
$$ C_{338}^2 = \frac{338 \times 337}{2} = 56953 $$
$$ N = 3 \times 56616 + 3 \times 56953 = 169848 + 170859 = 340707 $$

所以，原方程正整数解共有 **340707** 组。
