# 正 18 边形中的偶然点与多重共线分析

在正多边形中，两条对角线通常相交于一点。但当三条或更多条对角线相交于同一个非中心点时，该交点在平面几何与组合几何中被称为**偶然点（Adventitious / Accidental Intersection Point）**。

正 18 边形由于 $18 = 2 \times 3^2$，其内接圆心角基元为 $20^\circ$，其丰富的有理三角重合使之成为正多边形中偶然交点最密集、最经典的案例之一。

## 几何要素与坐标参数

### 1. 参与共点的 5 条对角线
设正 18 边形顶点按逆时针顺序依次为 $V_1, V_2, \dots, V_{18}$，外接圆半径为 $R$。相交于点 $P$ 的 5 条对角线分别为：
- $V_1 V_7$
- $V_2 V_9$
- $V_3 V_{12}$（经过外接圆心 $O$ 的主直径）
- $V_4 V_{15}$
- $V_5 V_{17}$

### 2. 交点 $P$ 的几何位置与闭形式距离
交点 $P$ 恰好位于主直径 $V_3 V_{12}$（极角 $\theta = 40^\circ$）上：
- **极坐标位置**：$(\theta, r) = \left(40^\circ,\, \dfrac{R}{2\cos 20^\circ}\right)$
- **距离中心精确值**：
  $$r = \frac{R}{2\cos 20^\circ} \approx 0.532088886\, R$$

---

## 围绕点 $P$ 的角度分布特征

5 条对角线自点 $P$ 发散出 10 条射线（分别指向 10 个对应顶点）。按逆时针方向绕点 $P$ 一周，10 个相邻顶角具有高度规则的二元周期性：

1. $\angle V_2 P V_3 = 40^\circ$
2. $\angle V_3 P V_4 = 40^\circ$
3. $\angle V_4 P V_5 = 30^\circ$
4. $\angle V_5 P V_7 = 40^\circ$
5. $\angle V_7 P V_9 = 30^\circ$
6. $\angle V_9 P V_{12} = 40^\circ$
7. $\angle V_{12} P V_{15} = 40^\circ$
8. $\angle V_{15} P V_{17} = 30^\circ$
9. $\angle V_{17} P V_1 = 40^\circ$
10. $\angle V_1 P V_2 = 30^\circ$

### 规律与几何意义
- **仅有两种整度数**：所有相邻顶角严格只有 **$30^\circ$** 与 **$40^\circ$** 两种，序列呈现回文对称周期：
  $$(40^\circ,\, 40^\circ,\, 30^\circ,\, 40^\circ,\, 30^\circ) \times 2$$
  每半周恰为 $40^\circ \times 3 + 30^\circ \times 2 = 180^\circ$。
- **圆周角与交角加权定理**：
  圆内两条弦相交于点 $P$，其夹角等于两端圆弧圆心角之和的一半：
  $$\angle = \frac{\widehat{\text{弧}_1} + \widehat{\text{弧}_2}}{2}$$
  例如对于 $\angle V_7 P V_9$，其一端弧为 $\widehat{V_7V_9}$（跨 2 格，弧度 $40^\circ$），另一端对顶弧为 $\widehat{V_1V_2}$（跨 1 格，弧度 $20^\circ$）：
  $$\angle V_7 P V_9 = \frac{40^\circ + 20^\circ}{2} = 30^\circ$$

## 经典应用：Langley's Adventitious Angles 问题

正 18 边形内部的这一五线共点构型，直接孕育了著名的初等几何世纪难题——**Langley 偶然角问题（1922）**。

### *Langley's Problem*

在 $\triangle ABC$ 中，$AB = AC$，$\angle BAC = 20^\circ$，$\angle ABC = \angle ACB = 80^\circ$。$D$ 是 $AC$ 边上一点，满足 $\angle DBC = 60^\circ$；$E$ 是 $AB$ 边上一点，满足 $\angle ECB = 50^\circ$。

求：$\angle EDB$ 的度数。

![Langley问题题目配图](https://raw.githubusercontent.com/crsando/picgo/main/p1_prob-20261020.svg)

### ***Solution***

在 $AC$ 上取一点 $G$，使得 $\angle CBG = 20^\circ$。连结 $DG, EG$。

![Langley问题解答配图](https://raw.githubusercontent.com/crsando/picgo/main/p1_sol-20261020.svg)

1. 在 $\triangle BCG$ 中，$\angle CBG = 20^\circ$，$\angle BCG = 80^\circ \implies \angle BGC = 80^\circ$，故 $BG = BC$。
2. 考察 $\triangle BCE$：$\angle EBC = 80^\circ$，$\angle ECB = 50^\circ \implies \angle BEC = 50^\circ$，故 $BE = BC$。
   结合 $BG = BC$，得 $BE = BG$。
   又 $\angle EBG = \angle ABC - \angle CBG = 80^\circ - 20^\circ = 60^\circ$，故 $\triangle BGE$ 是正三角形，得 $EG = BG = BE$，$\angle BGE = 60^\circ$。
3. 考察 $\triangle BDG$：
   $\angle DBG = \angle DBC - \angle CBG = 60^\circ - 20^\circ = 40^\circ$。
   在 $\triangle BCD$ 中，$\angle BDC = 180^\circ - 60^\circ - 80^\circ = 40^\circ$。
   故 $\angle BDG = \angle BDC = 40^\circ = \angle DBG \implies GD = GB$。
4. 综合以上：$GD = GE$（均等于 $BG$），故 $\triangle GDE$ 是等腰三角形。
   顶角 $\angle DGE = 180^\circ - \angle BGC - \angle BGE = 180^\circ - 80^\circ - 60^\circ = 40^\circ$。
   底角 $\angle GDE = \frac{180^\circ - 40^\circ}{2} = 70^\circ$。
5. 由第 3 步，$\angle BDG = 40^\circ$。
   因此：
   $$\angle EDB = \angle GDE - \angle BDG = 70^\circ - 40^\circ = 30^\circ$$

*（作图法：与第 6 题解法 1 一样，先截取等长线段 $BG = BC$ 产生等腰三角形，再得到正三角形 $\triangle BGE$。）*

## 正 18 边形偶然点全局统计

根据 Gerrit Bol (1936) 与 Bjorn Poonen & Michael Rubinstein (1998) 的理论，正 18 边形内部共有 **324** 个非中心多重交点：

| 共线重数 $k$ | 偶然点数量 | 轨道分布特征 |
| :--- | :--- | :--- |
| **3 线共点** | 216 个 | 分布在 9 个不同的旋转对称轨道上 |
| **4 线共点** | 54 个 | 分布在 3 个同心圆对称轨道上（$r \approx 0.508R, 0.684R, 0.778R$） |
| **5 线共点** | 54 个 | 分布在 3 个同心圆对称轨道上（内环 $2\sin 10^\circ$、中环 $\frac{1}{2\cos 20^\circ}$、外环 $1 - 2\sin 10^\circ$） |
| **总计** | **324 个** | 构成极高阶的二面体群 $D_{18}$ 旋转与轴反射对称几何星芒点阵 |
