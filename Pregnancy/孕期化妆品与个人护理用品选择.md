> [!summary] 先看结论
> 普通牙膏、洗发水、洗面奶、粉底/BB 霜、口红和润唇膏，孕期通常可以正常使用。选择重点是：**正规渠道、成分透明、基础配方、少叠加功效**。明确回避外用维 A 酸类；氢醌通常也建议回避。水杨酸不是“一律禁用”：ACOG 和 MotherToBaby 提到，含水杨酸、壬二酸、过氧化苯甲酰或果酸的非处方局部产品，在有需要时可按说明使用，但要避免高浓度、大面积、频繁刷酸和医美焕肤。

## 1. 证据和使用原则

### 1.1 不要只看“孕妇专用”

“孕妇专用”不是统一的医学认证，不能代替成分和用法判断。优先选择：

- 正规品牌、正规渠道；
- 有完整成分表、生产信息和备案信息；
- 功效少、配方简单、无来源不明植物复配；
- 不用“速效美白、祛斑、祛痘、生发”等成分不清的产品。

### 1.2 暴露量很重要

外用产品的吸收会受**浓度、使用面积、使用频率、是否封包、皮肤是否破损或发炎**影响。洁面和洗发水短时间后冲洗，通常比留敷在皮肤上的产品暴露低；局部点涂通常比全脸大面积使用低。

### 1.3 新产品先小范围试用

一次只换一种。先在耳后或下颌边缘小范围试用 1--2 天；出现持续红肿、刺痛、脱皮、瘙痒或水疱就停用。

## 2. 明确建议回避的成分

### 2.1 外用维 A 酸类和维 A 类抗老成分

孕期通常直接停用并咨询医生：

- 维甲酸、全反式维 A 酸、tretinoin；
- 阿达帕林、adapalene；
- 他扎罗汀、tazarotene；
- 视黄醇、retinol；
- 视黄醛/视黄醇醛、retinal、retinaldehyde；
- 其他 retinoid 或 retinoic acid 相关成分。

外用产品的吸收通常低于口服药，但专业建议仍普遍采取孕期回避原则。已经误用一两次，不等于一定有问题；记录产品、浓度、使用面积和时间，告诉产科医生即可。

### 2.2 氢醌

氢醌（hydroquinone）常见于美白、祛斑产品。由于经皮吸收相对较高，孕期建议回避。

### 2.3 高浓度酸类和医美项目

孕期不建议自行做：

- 高浓度水杨酸、果酸、复合酸焕肤；
- 大面积、频繁、封包式刷酸；
- 成分和浓度不清的医美祛斑、祛痘项目；
- 强挥发性化学品、酸液或喷雾操作。

## 3. 可以直接按基础款购买的用品

## 3.1 牙膏：优先含氟防蛀

### 怎么选

- 成人含氟防蛀牙膏；
- 常见成人配方约 1450 ppm 氟化物；
- 口腔敏感可选抗敏系列；
- 不必为了怀孕改成无氟牙膏。

### 可参考的产品线

- 高露洁全效/防蛀系列；
- 佳洁士防蛀系列；
- 舒适达基础防蛀系列；
- Elmex 防蛀系列。

这些是购买方向，不是对每个地区、每个批次配方的永久背书，购买时看实际包装。

### 用法

每天至少刷牙 2 次，刷后吐净，不要吞咽。孕期牙龈出血、肿胀较常见，但持续出血、牙痛、明显肿痛或口腔异味应看牙医。ADA 认为孕期必要的预防、诊断和牙科治疗可以进行，应提前告知牙医怀孕情况。

## 3.2 洗发水：日常基础清洁即可

普通洗发水在头皮短暂停留后冲洗，通常不需要特别换成“孕妇专用”。优先选温和、香味不重、洗后不紧绷的基础款。

### 可参考

- 施巴温和洗发露；
- 妙思乐温和洗发露；
- 丝塔芙温和洗发水；
- 其他品牌的普通日常清洁线。

### 谨慎

- 维 A 类头皮功效产品；
- 成分不明的“速效生发/育发”产品；
- 高浓度水杨酸头皮刷酸；
- 没有清晰药物成分标示的强效防脱产品。

脱发、严重头屑、头皮炎症不要靠网红洗发水解决，需让皮肤科医生判断。

## 3.3 洗面奶：温和、少刺激

### 可参考

- 丝塔芙温和洁面乳；
- CeraVe 适乐肤水润洁面或泡沫洁面；
- 理肤泉特安洁面；
- 芙丽芳丝净润洗面霜；
- 雅漾舒缓特护洁面乳。

### 选择和用法

避开磨砂颗粒、强去角质和洗后明显紧绷的产品。洁面产品中的低浓度水杨酸属于短时间接触后冲洗，通常低于留敷型暴露；如果只是基础清洁，没有必要专门追求含酸洁面。

## 3.4 粉底液、BB 霜、气垫：通常可以用

### 购买原则

底妆通常属于可以使用的日常化妆品。检查实际配方是否含：

- 维 A 酸类或视黄醇/视黄醛；
- 氢醌；
- 高浓度水杨酸或强效焕肤成分；
- 成分表不完整的美白、祛斑或祛痘活性物。

### 可参考的产品线

- 雅诗兰黛沁水粉底；
- 兰蔻普通粉底线；
- Make Up For Ever HD 粉底；
- Maybelline Fit Me 粉底；
- 薇诺娜正规底妆/防晒底妆线。

品牌和产品配方会更新，以上只代表候选方向，不能替代对手上产品成分表的核对。

### 使用注意

BB 霜、气垫标注的 SPF 通常不足以替代足量防晒。粉扑、刷具定期清洗或更换，不要和别人共用。晚上正常卸妆，避免用力摩擦造成皮肤屏障受损。

## 3.5 口红和润唇膏：正规产品可用

### 可参考

- 凡士林经典润唇膏；
- 依泉润唇膏；
- 雅漾润唇膏；
- Fresh 澄糖润唇膏；
- MAC、Dior、YSL、NARS 等正规渠道口红。

### 避免

- 无完整成分表的手工口红、三无产品；
- 刺痛、麻木、灼热感很强的“速效丰唇”产品；
- 含高浓度水杨酸、刺激性精油或不明药物成分的唇部产品。

正规上市口红不需要因为担心“重金属”而完全禁用；关键是来源可追溯。吃饭前擦掉口红，可以减少不必要吞咽。

## 4. 祛痘和功效成分：按强度管理

| 成分 | 孕期建议 | 实际用法 |
| --- | --- | --- |
| 水杨酸 | 需要时可考虑，不是一律禁用 | 低浓度、局部、低频率；避免高浓度刷酸、大面积和封包 |
| 壬二酸 | 通常是较常被考虑的孕期痘肌成分 | 从低频率开始，注意刺激；最好让医生确认具体浓度 |
| 过氧化苯甲酰 | ACOG/MotherToBaby 提到可在需要时考虑 | 局部、短期、按说明用，可能干燥刺激 |
| 果酸/甘醇酸 | 低浓度、低频率通常较温和 | 不与多种酸叠加，孕期避免焕肤级产品 |
| 烟酰胺 | 通常可用 | 高浓度也可能刺激，基础浓度更稳妥 |
| 维生素 C | 通常可用 | 选择配方简单且耐受的产品 |
| 维 A 酸、阿达帕林等 | 回避 | 包括处方药和抗老产品中的相关成分 |
| 氢醌 | 回避 | 美白、祛斑产品常见 |

ACOG 和 MotherToBaby 的重点是“需要时、正确使用、读清标签”。同一瓶产品可能混合多种活性成分，所以不要只看一个成分就判定整瓶安全。

## 5. 家人使用水杨酸等酸，孕妇需要担心吗？

### 普通护肤：通常没有问题

家人使用普通浓度水杨酸、壬二酸、果酸或维 A 类护肤品，孕妇在旁边正常生活、拥抱、共处或睡在一起，通常不会造成有意义的孕期暴露。MotherToBaby 也指出，父亲或精子提供者的这类暴露通常不太可能增加妊娠风险。

### 做好基本卫生

- 家人涂完药膏或功效产品后洗手；
- 不共用面霜、化妆棉、刷酸工具、毛巾和枕巾；
- 避免刚涂完的产品大面积蹭到孕妇皮肤、眼睛、嘴唇或破损皮肤；
- 不在孕妇身边做高浓度化学焕肤、酸液或强挥发性喷雾操作；
- 发生泼洒或刺激性气体时，先离开现场并通风。

家人不是孕妇，因此不需要把日常护肤品全部换成孕期配方；关键是不要让高浓度产品直接接触孕妇，也不要让孕妇接触未冲洗的药膏残留。

## 6. 一个更稳妥的日常组合

### 早上

1. 温和洗面奶，或只用温水；
2. 基础保湿；
3. 正规防晒；
4. 需要时使用粉底、BB 霜或口红。

### 晚上

1. 卸妆；
2. 温和洁面；
3. 基础保湿；
4. 如果痘痘确实需要治疗，再根据医生意见选择壬二酸、低浓度局部水杨酸或其他适合的方案。

孕早期尤其建议减少同时使用的功效产品数量。皮肤问题不严重时，基础护理比“猛攻”更合适。

## 7. 购买前清单

- [ ] 正规渠道购买，有完整成分表；
- [ ] 没有 tretinoin、adapalene、tazarotene、retinol、retinal 等维 A 类；
- [ ] 没有 hydroquinone（氢醌）；
- [ ] 没有高浓度酸类或医美焕肤用途；
- [ ] 没有“速效美白、祛斑、祛痘、生发”等成分不明宣传；
- [ ] 新产品先小范围试用；
- [ ] 出现持续刺痛、红肿、脱皮、瘙痒或水疱后停用；
- [ ] 处方药、药膏、祛痘药和生发药先问产科或皮肤科医生。

## 8. 什么时候必须找医生确认

- 使用了处方痤疮药、祛斑药、生发药或不确定的复方药；
- 大面积、长期使用高浓度酸类或维 A 类产品；
- 发生化学品泼洒、明显吸入或皮肤灼伤；
- 皮肤大面积红肿、起疹、脱皮、感染或持续瘙痒；
- 想开始长期治疗痤疮、湿疹、头皮炎、脱发或色斑。

> [!warning] 提醒
> 本笔记用于日常筛选，不替代产科医生或皮肤科医生的个体化判断。不要自行停用维持健康所必需的处方药；把产品名称、浓度、使用面积和频率带给医生评估。
