原标题：Global Fixed Income Weekly: Strategy Update

中文标题：全球固定收益周报：策略更新

关键词：全球利率、美债回购、美联储沟通、国债期货、通胀风险溢价、欧洲担保债、欧盟债券、超主权债

作者：Francis Yared, Matthew Raskin, Soniya Sadeesh, Bernd Volk, Steven Zeng, Ioannis Sokos, Gabriele Cozzi, Mingyue Xin, Markus Heider, Andrew Fu, Shoki Omori

### 摘要

德意志银行本期全球固收周报的核心变化是政策沟通和供给结构同时变得更主动。美国财政部意外将长期国债回购规模翻倍，绝对规模每季仅增加160亿美元，直接压低期限溢价的作用有限，但在季度再融资窗口之外择时宣布，说明财政部愿意用沟通和债务管理工具约束长端收益率。这降低了持有曲线陡峭化的吸引力，却强化长期掉期利差走阔和利差曲线陡峭化。与此同时，6月美联储会议后美国利率的日常波动和对数据意外的敏感度反而下降，市场对减少前瞻指引后波动上升的预期尚未兑现。欧洲方面，欧元基准担保债年内发行同比增长17.4%，但其相对公司债和高级银行债表现落后，短端利差仍有价值；欧盟债5年至10年曲线相对德国复兴信贷银行过陡，德国州债预算压力上升但信用韧性仍在。

### 主要观点

- 美国财政部把长期票息国债回购规模翻倍，若永久执行，每年新增约640亿美元。该规模相对债券市场和量化宽松经验仍小，直接对十年期收益率的压低作用有限；更重要的是宣布发生在常规季度再融资流程之外，暴露出更主动的债务管理反应函数。
- 新增长期回购在票息发行规模保持不变时将由短期国库券融资，只会轻微缩短平均到期年限。财政部以战术沟通抑制长端收益率，提高做空久期和持有现金曲线陡峭化的政策风险，但长期供给转为国库券或中段发行会支持掉期利差曲线陡峭化。
- 6月美联储会议后，隔夜融资利率期货至30年期美债的平均绝对日变动反而略有下降，短端降幅更明显。CPI和就业报告公布后的两年、十年收益率反应没有超过此前经验，回归结果显示利率对经济数据意外的敏感度显著下降。
- 美联储沟通的影响主要集中于短端，6月后多数期限对官员讲话的敏感度也下降，但统计显著性较弱。结果与投资者关于减少前瞻指引会提高日常波动的预期相反，也给希望从市场价格获取政策信号的美联储带来识别难题。
- 美国国债9月期货移仓预计集中在8月20日至26日，以避开会议纪要和杰克逊霍尔。除五年合约外多数合约定价对应较晚交割；非价格敏感投资者在各期限保持净多，十年、超长期及最长期合约面临更强移仓走弱压力。
- 日本通胀分布的上行偏度与五年后五年国债远期利率高度相关，美国也呈现类似关系，说明期限溢价对通胀尾部风险敏感。日本4月至5月汇率干预后短期美债持有量下降一半以上，显示干预融资会消耗高流动性外汇储备资产。
- 欧元基准担保债年内总发行1341亿欧元，同比增加17.4%，即使法国和德国发行偏少，25个国家和104家银行参与仍可能推动全年发行超过原先1680亿欧元估计。加拿大增量最大，非欧元区发行人国际化进一步提高供给多样性。
- 担保债自3月底以来相对公司债和高级银行债表现落后，德国担保债年内也弱于其他国家同类债。新券订单强、定价较初始指引收紧6至7个基点，说明绝对收益率吸引买盘；报告继续看好相对掉期利差，偏好六年以内短端。
- 欧盟债年内相对德国州债走弱，五年至十年曲线相对德国复兴信贷银行现金债约陡10个基点，按固定期限指数约陡3个基点。十年欧盟债虽较国内生产总值加权欧元区国债低约7个基点，但凭借更高平均评级仍有进一步收紧依据。
- 德国州和市政预算受到中东战争拖累增长、税收减弱、人员成本上升和市政赤字扩大的共同压力。2025年市政资本账户后赤字超过280亿欧元，州政府承担更高转移支付压力；评级机构仍认为州级信用质量有韧性，报告维持与德国联邦债相近的判断。
- 非欧洲超主权机构年内发行约1323亿美元，同比下降19%，其中国际复兴开发银行发行减少213亿美元，解释总降幅约三分之二。较小机构发行增加不足以抵消主要发行人减少，欧元、美元和英镑计价供给均低于上年同期。
### 论述逻辑

财政部意外扩大长期回购 → 实际规模较小但政策反应函数更主动 → 市场提高对后续供给干预和战术沟通的权重 → 长端现金收益率上行空间受到约束 → 现金曲线陡峭化仓位风险回报下降 → 长债供给转为国库券或中段发行 → 长端掉期利差及利差曲线陡峭化受益；与此同时，美联储减少前瞻指引 → 日常利率波动并未上升且数据敏感度下降 → 政策信号识别更困难；欧洲高担保债供给与相对落后表现 → 新券高收益吸引真实资金 → 短端担保债利差具备价值 → 欧盟债相对州债和德国复兴信贷银行曲线偏陡 → 跨发行人相对价值机会增加。

### 关键展望

- 财政部后续仍可能通过回购、发行构成和临时沟通干预长端，但每次行动的边际效果可能递减，过度偏离规则化框架也会损害制度信誉并抬高期限溢价。
- 杰克逊霍尔和下一次美联储会议将检验较少前瞻指引是否真正提高事件波动；现有证据更支持日常波动下降、单次会议波动增大的组合。
- 欧元基准担保债全年发行大概率超过2025年1590亿欧元，也可能高于原先2026年1680亿欧元估计，但强劲订单和相对便宜估值限制利差显著走阔。
- 欧盟五年至十年曲线相对德国复兴信贷银行仍偏陡，若供给节奏和信用评价稳定，中长段欧盟债的相对表现存在修复空间。
- 德国州级财政压力将持续，但联邦支持、法律框架和较高信用质量使系统性恶化风险有限，短端州债和担保债仍可进行精选。
- 非欧洲超主权债供给下降有利于存量券技术面，美元发行减少尤其明显，后续需观察主要多边开发银行是否在年末补发。
### 推荐标的

- 偏好美国长期掉期利差走阔及利差曲线陡峭化，财政部回购减少长端现金债净供给，而替代融资更多落在国库券或曲线中段。
- 谨慎持有美国现金国债曲线陡峭化，财政部可能继续以回购、发行构成和沟通限制长端收益率，政策尾部风险已明显提高。
- 国债期货移仓中偏空两年、五年、长期和最长期日历价差，十年期温和偏空，超十年期中性，依据仓位、净基差和最便宜交割券价值综合判断。
- 偏好六年以内欧元担保债相对掉期，年内相对公司债和高级银行债落后，新券订单却保持强劲，估值和技术面共同提供支撑。
- 关注德国担保债相对其他国家担保债的修复机会，短端年内表现落后较多，而法律保护、系统支持和真实资金需求没有同步恶化。
- 关注欧盟五年至十年曲线相对德国复兴信贷银行趋平，现金债历史比较显示约有10个基点的过度陡峭。
- 选择性持有十年欧盟债相对国内生产总值加权欧元区国债，欧盟平均信用评级更高，当前约7个基点的收益率优势仍有收窄空间。
- 关注非欧洲超主权机构存量债，年内总供给同比下降19%，主要币种发行均减少，较轻的供给压力有利于二级市场技术面。
